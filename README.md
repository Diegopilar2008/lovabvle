# Pata & Companhia 🐾

Loja virtual demonstrativa de produtos para cães e gatos, construída com React e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Publicar

```bash
npm run build
npm run preview
```

## Antes de vender de verdade

- Substituir produtos, imagens, preços e informações demonstrativas pelos dados reais.
- Configurar um meio de pagamento/checkout seguro.
- Definir frete, prazos, política de troca, privacidade e contato da loja.
- Não anunciar estoque, avaliações ou garantias que ainda não existam.

O carrinho atual funciona no navegador, mas o botão de pagamento é demonstrativo e ainda não processa pedidos.
